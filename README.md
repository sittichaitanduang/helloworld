# 🚀 ASCII Rocket Launch Animation

A simple Python terminal animation that simulates a rocket launch using ASCII art.

## ✨ Features

- Animated rocket launch
- ASCII art frames
- Terminal screen clearing
- Smooth launch effect
- Beginner-friendly Python project

---

## 📦 Requirements

- Python 3.x

No external libraries required.
